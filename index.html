ALBOE Shorts Publisher

ALBOE Shorts Publisher is a private tool used only by the owner of the A Little Bit of Everything YouTube channel. It runs on the owner's own computer and uses the official YouTube Data API to:

  • upload the channel's own finished Shorts and set their title, description and visibility;
  • upload caption files for those videos;
  • read basic channel information to confirm it is publishing to the right channel.

It is not offered to other users and does not access anyone else's account.
