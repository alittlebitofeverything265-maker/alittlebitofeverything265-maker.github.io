Privacy Policy

ALBOE Shorts Publisher · Last updated: October 27, 2026

Who we are

ALBOE Shorts Publisher is a private tool operated by the owner of the YouTube channel A Little Bit of Everything. It is used only to publish that channel's own videos.

What data the app accesses

When the channel owner signs in with Google, the app requests these YouTube permissions:

  • youtube.upload — to upload the channel's videos;
  • youtube.readonly — to read the channel's ID and title and check an upload's processing status;
  • youtube.force-ssl — to upload caption files for the channel's own videos.

The app does not read emails, contacts, comments, subscribers, watch history or any data from other YouTube users.

How data is used and stored

  • Google user data is used only to publish and verify the channel owner's own videos.
  • The OAuth token is stored only on the owner's computer, encrypted with Windows Data Protection (DPAPI). It is never sent to any server other than Google's.
  • No data is sold, shared with third parties, used for advertising, or used to train AI models.

Google API Services User Data Policy

ALBOE Shorts Publisher's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions or through Google security settings. Deleting the app's local secrets folder removes the stored token.
